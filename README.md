# SEI Assessment Coach

Internal Next.js app for the **AI Assessment & Strategy Agent**: consultants practice with voice or text and receive a **learning summary** (four dimensions, confidence, highlights).

See [GUIDE.md](GUIDE.md) for commands and workflow. The technical rulebook is [CLAUDE.md](CLAUDE.md).

Generated by `/bootstrap`.

## Project structure

```
app/                 # Routes and layouts (App Router)
```

## Quick start

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (default [http://localhost:3000](http://localhost:3000)).

## Local development (scripts)

| Script | Use |
